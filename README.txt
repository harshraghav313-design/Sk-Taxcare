# SK TaxCare Website - Frontend Starter

## Included files
- `index.html`
- `style.css`
- `script.js`

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. Keep all three files in the same folder.

## Important: backend is not connected
This package provides the responsive public-facing website interface and frontend interactions.
The enquiry form and customer status lookup intentionally do not save or retrieve real data yet.

The final planned features require a secure backend/database:
- Enquiry storage and reference-number generation
- Admin authentication with password hashing and CAPTCHA verification
- Admin dashboard and controlled status transitions
- Customer status lookup using reference number + registered mobile number
- Secure profile changes

Do not add an admin password or private database credentials to `script.js`.
Do not publish this as a fully working enquiry-management website until backend integration and security checks are complete.
